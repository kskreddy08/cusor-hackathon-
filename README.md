# Nearby — Live Chat (no install)

**Open the link → Open Lounge is always on → chat.**

## Live link (no `./start.sh` needed)

```
https://nearby-chat-live.onrender.com
```

Or: https://nearby-chat-weld.vercel.app (redirects to live server)

First visit may take ~30 seconds while the free cloud server wakes up. Then **Open Lounge** is always there.

## Host a room

Open the link → tap **+ Host a room** → others can join.

## Deploy your own live server

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/kskreddy08/cusor-hackathon-)

## Local WiFi mode (optional)

```bash
./start.sh
```

For same-WiFi-only chat without the cloud.
